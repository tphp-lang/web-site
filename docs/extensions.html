扩展系统

通过 #import 指令导入内置扩展，扩展函数直接编译进二进制。

#import 语法

<?php
#import pcntl

class Main {
    public function main(): void {
        $pid = pcntl_fork();
    }
}

内置扩展

pcntl posix openssl calendar exif pcre pdo pdo_mysql sqlite3 stream fileinfo filter hash iconv
安全模型：#import 受扩展名白名单（正则 \w[\w\-]*）+ 工作区边界校验（realpath 后必须在 ext/ 目录内）双重约束，杜绝路径穿越。
