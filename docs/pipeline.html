编译流水线

从 PHP 源码到原生二进制的完整 AOT 流水线：

PHP → Lexer → Token[] → Parser → AST → CodeGenerator → .c → 编译器 → 二进制

阶段说明

  • Lexer — 逐字符扫描，约 75 种 Token，支持字符串插值 / heredoc
  • Parser — 递归下降，运算符优先级完整
  • CodeGenerator — 访问者模式，生成类型安全的 C 代码
  • C 运行时 — COS 风格对象系统（16B 头），setjmp/longjmp 异常，ROPE 字符串拼接，128 槽数组/对象复用池，64KB 字符串池
  • 编译器 — 内置 TCC（mob 分支），支持 GCC / Clang
