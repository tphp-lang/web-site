## 术语表 {#glossary}

本表按字母顺序收录 tphp 专有术语，每个术语给「一句话定义 + 通俗类比 + 出现在哪篇文档」三段式说明。

| 术语 | 一句话定义 | 通俗类比 | 出现在 |
|------|-----------|---------|--------|
| **AOT**（Ahead-Of-Time，提前编译） | 程序运行前就把源码一次性编译成原生机器码的方式；tphp 把 PHP → C → 二进制，运行时无需解释器或虚拟机。 | 像把菜提前做好打包带走，到地方直接吃，不是现点现做。 | intro / pipeline |
| **CSP**（Communicating Sequential Processes，通信顺序进程） | 一种以「进程间传消息」取代「共享内存加锁」的并发模型，tphp 的 `Channel`/`chan_select` 即源于此。 | 像工人之间靠传送带递零件，各自干各自的活，不用挤同一个工具箱抢着拿。 | threads |
| **defer** | tphp 独有语句，注册一段清理代码，在函数退出时按后进先出顺序执行，零运行时开销。 | 像 `finally` 的兄弟——不管从哪扇门离开房间，都会顺手把灯关掉、把门带上。 | syntax |
| **Generator**（生成器） | 一种能"暂停-恢复"的函数，遇到 `yield` 暂停并产出值，下次被驱动时从原地继续。 | 像一个能随时按下暂停键的函数，每次按播放吐一个值，按暂停记住位置，下次接着播。 | syntax / functions |
| **PHPC** | tphp 的 PHP ↔ C 双向互操作层，通过 `#include`/`#flag`/`C->call`/`C.Type` 等指令直接调用 C 函数、读写 C 结构体。 | 像 PHP 和 C 之间的翻译官兼快递员，两边的话它都懂，东西来回递不用你操心。 | phpc / extensions |
| **Property Hook**（属性钩子） | PHP 8.4 引入的属性语法，给属性挂上 `get`/`set` 钩子，访问和赋值时自动走自定义逻辑；tphp 编译为 getter/setter 方法。 | 像给房门装了智能门禁：进出门（读写属性）都要刷一下卡（走钩子逻辑），但用的人感觉还是直接推门。 | syntax / oop |
| **Thread-Local**（线程本地存储） | 每个线程各自持有一份独立的运行时数据，互不干扰，无需加锁。 | 像每个工人都自带一套工具箱，各用各的，不用排队等公共工具箱，自然就不会打架。 | threads |
| **trait** | PHP 的代码复用机制，tphp 在编译期复用到使用它的类里，零运行时开销。 | 像一批可复用的方法"零件"，哪个类要用就焊到哪个类上，用完即拆模具，成品里看不出拼接痕迹。 | oop / syntax |
| **yield** | Generator 函数中暂停并产出一个值的语句，可带键值（`yield $k => $v`），下次驱动时从暂停处继续执行。 | 像往传送带上放一个零件然后按下暂停，等下游取走、发信号后再接着生产下一个。 | functions |
| **类型固定** | tphp 核心特性：变量类型在首次赋值时确定，此后不可变；由此 `===` 与 `==` 等价，零运行时类型检查。 | 像签了合同的工种——入职定岗后不能再换岗，但也省去了每天核对工牌的麻烦，效率反而高。 | variables / intro |
| **命名空间**（namespace） | PHP 用 `namespace A\B` 给代码划分子空间，避免同名冲突的机制。 | 像给文件归类放进不同文件夹，同名文件只要不在同一个文件夹里就不会撞车。 | syntax |
| **协程** | 一种比线程更轻量的并发执行单元，可在函数内部暂停让出执行权。 | 像一个人同时做几道菜：这边水烧着就去切菜，切完再回来看锅——单线程但会"分身"。 | threads |
