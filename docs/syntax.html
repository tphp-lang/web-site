语法特性

基于 PHP 8.5 强类型语法，约 80% PHP 兼容性。下列特性均已在 AOT 编译器中实现。

控制流

if/elseif/else while do-while for foreach switch match break/continue goto

OOP 面向对象

class extends abstract interface implements trait + use enum __construct(public $x) __destruct static / final / readonly instanceof self:: $this ?-> 空安全

闭包

function() use($x) {} fn($x): T => expr 多捕获 嵌套闭包

异常

try/catch/finally throw error() 抛出 Type|Exception 返回类型 never

类型系统

int float string bool array array<T> 泛型数组 callable void mixed self 类类型

运算符

完整 15 级优先级 三元 ?: 空合并 ?? 太空船 <=>

命名空间

namespace A\B use A\{B,C} 分组导入 use function / const

Generator 生成器

yield yield $k => $v send() getReturn()
不支持：eval()、$$var、include/require、__call/__get/__set。 这些特性在 AOT 物理不可行，详见 README 中的替代方案。
